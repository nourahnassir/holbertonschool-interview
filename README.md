# UTF-8 Validation

This project contains a Python algorithm to determine if a given data set represents a valid UTF-8 encoding, developed as part of the Holberton School interview preparation curriculum.

---

## Requirements & General
* **Language:** Python 3 (version 3.4.3+)
* **Style:** PEP 8 (version 1.7.x)
* **Execution:** All files must be executable and end with a new line.

---

## Tasks & Files

| File Name | Description |
| :--- | :--- |
| `0-validate_utf8.py` | Method `validUTF8(data)` that checks if a list of integers represents a valid UTF-8 encoding. |
